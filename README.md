# Biruk Ahmye Portfolio

A modern personal portfolio website for Biruk Ahmye, built with React, TypeScript, and Vite. The project showcases professional experience, AI/ML engineering work, problem-solving skills, featured projects, and contact information in a polished one-page portfolio design.

## Features

- Modern responsive portfolio layout
- Dark/light theme support
- About section with academic and professional background
- Experience and journey timeline
- Skills and technology highlights
- Featured projects with interactive modal view
- AI engineering and architecture sections
- Contact form that opens the user's email client
- Smooth scroll-based reveal animations

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Motion library for animations

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the app locally

```bash
npm run dev
```

The app will run on:

```bash
http://localhost:3000
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview production build

```bash
npm run preview
```

## Scripts

```bash
npm run dev      # start Vite dev server
npm run build    # create production build
npm run preview  # preview the build locally
npm run lint     # TypeScript check
```
